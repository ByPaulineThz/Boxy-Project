# Boxy — Générateur de Box Shadow CSS

## Concept
Boxy est un outil en ligne simple et pratique pour créer, tester et copier des ombres CSS en temps réel. J'ai pensé et développé ce projet pour offrir une expérience fluide tout en utilisant des technologies modernes.

## Design et utilisation
L'interface est facile à prendre en main : on ajuste le flou, la taille ou la couleur avec des curseurs, et l'ombre change directement à l'écran. Une fois le résultat voulu obtenu, on peut copier le code CSS en un clic. Le design fonctionne aussi bien sur ordinateur que sur mobile grâce à Tailwind CSS et PostCSS, qui garantissent un style propre et bien adapté à tous les navigateurs.

## Stack Technique
L'application s'appuie sur React et Redux Toolkit pour gérer les données et synchroniser tous les paramètres d'ombre de façon fluide et sans ralentissement. L'utilisation de Vite permet un affichage et un chargement ultra-rapides, tandis qu'ESLint assure un code propre, bien structuré et facile à faire évoluer.
